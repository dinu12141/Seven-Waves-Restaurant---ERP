4. SECURITY & ACCESS CONTROL

4.1 Implemented Security Measures

  • Row Level Security (RLS) enabled on all database tables
  • Role-Based Access Control (RBAC) — Admin, Manager, Finance, HR, Cashier, Waiter, Kitchen, Delivery
  • All 28+ reporting views converted to SECURITY INVOKER (no privilege escalation)
  • ~140 PostgreSQL functions hardened with fixed search_path
  • Frontend route guards enforce role-based page access
  • Supabase Auth with session management and token refresh
  • Rate limiting on QR authentication endpoints
  • HTTPS enforced (Vercel SSL)

4.2 Client Responsibilities

  • Change all default admin passwords immediately after handover
  • Enable Leaked Password Protection in Supabase Auth Dashboard
  • Keep Supabase service key confidential — never expose in frontend code
  • Manage user roles and permissions through the Admin Panel only
  • Regularly review the Admin AI Security Audit alerts
